## Overview
Web browser extension to create useful keyboard shortcuts:

1. Duplicate current tab
2. Duplicate current tab to a new window
3. Pop out (move) current tab (or multiple highlighted tabs) to a new window
4. Open a blank new tab to immediate right of current tab (instead of all the way to the right)

*Tip: Even without this extension, it's possible to middle-click the browser's refresh button to duplicate the current tab.*

## Installation
